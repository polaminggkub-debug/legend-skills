# Mission: สั่ง AI ให้ส่งงานที่ตรวจรับได้

## Why
ใช้หลักฐานจากการทำงานร่วมกันใน GitHub เพื่อสั่ง AI ให้เปลี่ยนเป้าหมายเป็นงานย่อยที่มีขอบเขตและเกณฑ์รับงานชัดเจน แล้วตรวจผลตั้งแต่ issue, PR, review, test จนถึง merge ได้ด้วยตนเอง นำชุดข้อมูลไปเรียนต่อกับ ChatGPT ทีละบทได้

## Success looks like
- เขียน task brief ที่มีเป้าหมาย ขอบเขต เกณฑ์รับงาน และหลักฐานตรวจได้
- แบ่งงานตามความรับผิดชอบและลำดับ dependency พร้อมจุดส่งมอบ
- เปลี่ยนคำทักท้วงจาก review เป็นการแก้และการตรวจซ้ำที่สืบย้อนถึง commit ได้
- แยกคำกล่าวว่าเทสผ่าน ผล CI การอนุมัติ และการ merge ได้
- ประเมินหลักฐานการใช้ AI โดยไม่เหมารวมทั้ง repository

## Constraints
- อธิบายภาษาไทย ใช้ศัพท์อังกฤษที่จำเป็นพร้อมคำแปล
- เก็บ Markdown สำหรับ ChatGPT และบทเรียน/แบบฝึกหัดที่เปิดอ่านได้จาก repository เดียวกัน
- เน้นโปรเจกต์ใหญ่และมีหลายผู้ร่วมงาน อายุราว 1–2 ปี; ระบุกรณีเปรียบเทียบที่เก่ากว่าอย่างชัดเจน
- ค้นกว้าง แต่ให้ความสำคัญกับความลึกของบทสนทนาและหลักฐานมากกว่าจำนวนชื่อโปรเจกต์

## Out of scope
- สอน lint/guardrail ซ้ำทั้งชุดเดิม
- ประเมินสัดส่วนโค้ด AI ทั้งโปรเจกต์โดยไม่มีข้อมูลรองรับ
